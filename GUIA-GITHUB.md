# Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie todos os arquivos deste projeto.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment → Source**, escolha **GitHub Actions**.
4. Abra a aba **Actions** e aguarde o fluxo “Publicar apresentação” terminar.
5. O endereço publicado aparecerá em **Settings → Pages**.

## Usar o celular como controle

1. Abra o endereço do GitHub Pages no computador.
2. Inicie a apresentação.
3. Clique em **Controle remoto**, ao lado do cronômetro.
4. Escaneie o QR Code com a câmera do celular.
5. Aguarde aparecer **Celular conectado** e passe os slides pelo telefone.

O computador e o celular precisam estar com acesso à internet. Não precisam estar na mesma rede Wi-Fi. O QR Code cria uma sessão nova e temporária cada vez que o controle é iniciado.

Faça um teste antes da apresentação. Se a rede da escola bloquear a conexão direta, conecte o computador e o celular ao mesmo ponto de acesso/hotspot do telefone.
