# Apresentação — Cartas de um Diabo a seu Aprendiz

Este pacote funciona sem internet e também pode ser publicado no GitHub Pages.

## Usar no pendrive

1. Extraia o arquivo ZIP no pendrive.
2. Abra a pasta extraída.
3. Dê dois cliques em `index.html`.
4. Para apresentar sem as barras do navegador, pressione `F11`.

Não mova o `index.html` para fora da pasta, pois ele precisa das pastas e arquivos que o acompanham.

## Controles

- Clique na capa para começar.
- Setas direita e esquerda: avançar e voltar.
- `Page Down` e `Page Up`: avançar e voltar.
- `Home`: primeiro slide.
- `End`: último slide.
- `Esc`: retornar à capa e reiniciar o timer.
- Ao entrar no slide final, o timer pausa. Se voltar, ele continua de onde parou.

## Colocar no GitHub

1. Crie um repositório.
2. Envie o conteúdo desta pasta para a raiz do repositório.
3. Se quiser publicar como site, ative o GitHub Pages nas configurações do repositório e escolha a branch que contém os arquivos.

O arquivo inicial já se chama `index.html`, portanto não precisa de compilação.

## Estrutura

- `index.html`: apresentação.
- `styles.css`: aparência e responsividade.
- `script.js`: timer e navegação.
- `assets/`: ilustrações utilizadas.
